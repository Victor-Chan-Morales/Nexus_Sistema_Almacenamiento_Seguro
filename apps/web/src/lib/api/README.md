# Cliente API (pendiente)

Mantenga aquí `fetch`/clientes tipados cuando `CONTRACTS.md` tenga aprobación de equipo. La configuración pública se limita a `NEXT_PUBLIC_API_BASE_URL`; nunca guarde aquí tokens, passwords, credenciales de PostgreSQL o claves MinIO.

No agregue mocks silenciosos: los datos de desarrollo deben vivir en una implementación explícita y estar etiquetados como datos de maqueta.
